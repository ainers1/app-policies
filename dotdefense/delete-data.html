도트 머지 디펜스 데이터 삭제 안내

앱: 도트 머지 디펜스 (Android, com.ainers1.dotdefense) · 개발자: 스토어 등록정보의 개발자

계정 및 데이터 삭제 방법 (요약)

앱에는 별도 회원 계정이 없고, "구글 로그인"은 이용자 본인의 드라이브에 백업하는 데만 씁니다. 개발자 서버가 없어 개발자가 보관하는 데이터는 없습니다. 아래를 하면 앱과 관련된 데이터가 모두 지워집니다.

  1. 앱 타이틀 화면 ☁️ 백업 → 백업 지우기 (드라이브의 백업 파일 삭제) → 연결 해제
  2. 앱 삭제 (기기 안의 기록·진행 삭제)

삭제되는 데이터: 기기 안의 게임 기록·진행, 드라이브의 백업 파일. 개발자가 따로 보관하는 데이터가 없어 추가 보관 기간도 없습니다.

앱 없이 드라이브 백업 지우기

  1. 컴퓨터에서 구글 드라이브 설정 → 앱 관리 → 도트 머지 디펜스 옆 옵션 → 숨겨진 앱 데이터 삭제
  2. 앱 접근 권한 해제: Google 계정 → 타사 앱 및 서비스 → 도트 머지 디펜스 → 액세스 권한 삭제

Data deletion (English)

Dot Merge Defense has no developer server and no developer-held account or data. In the app: title screen → ☁️ Backup → Delete backup → Disconnect, then uninstall the app. Without the app: Google Drive on the web → Settings → Manage apps → 도트 머지 디펜스 → Options → Delete hidden app data, and remove access at Google Account → Third-party apps & services.
